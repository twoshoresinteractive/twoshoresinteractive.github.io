# Page artwork sources

This folder is independent of the main portfolio assets. Created 23 November 2026.

- `manor.webp` is a web export of the game’s `game/art/menu-background.png`.
- `investigation.webp` is a web export of `game/art/loading-investigation.png`, shown as story artwork, not a gameplay screenshot.
- `wrong-turn.webp`, `arrival.webp`, and `forecourt.webp` are unaltered-content web exports of actual development captures `output/validation/arrival-0-1280.png`, `arrival-2-1280.png`, and `revealed-umbrella-1280.png`.
- `game-icon.svg` and `manor-panel.svg` are editable original game vectors copied from `game/art/`.
- `lantern.svg`, `key.svg`, `moon.svg`, and `divider.svg` are original editable vectors drawn in code for this page. `manor.css` is the editable theme source.

Game source project: `Spooky Point and Click Game`, beside this portfolio workspace. Its original PNG artwork, editable sources, generation prompts, and provenance remain there under `art/`, `game/art/`, and `docs/`. The game artwork is project-specific, created with AI assistance; it is not public-domain or third-party stock artwork. Preserve the game’s provenance records for future distribution. This page introduces no external fonts, stock assets, paid services, or runtime libraries. Typography uses locally available system fonts.

- `fog.svg` is original editable vector mist drawn for this page. Its two CSS layers animate with transforms, become still for reduced motion, and pause in background tabs via `fog.js`. No external textures are used.
